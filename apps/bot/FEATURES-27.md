## Итого
- Бот: ✅ 21, 🟡 6, ❌ 0. Веб: ✅ 21, 🟡 6, ❌ 0. Отсутствующих функций нет, но ни одна не подтверждена live.
- Причины 🟡: навигационное состояние бота в памяти процесса (№12, 20, 22), отсутствующие поля контракта (№21, 24, 26), нерешённая ответственность за событие (№25) и ограниченная правка ветки в боте (№12). Сценарии восстановления после рестарта и выбора региона подготовлены в `test/restart-recovery.pending.ts` (сейчас 7/7 ожидаемо падают); после публикации полей контракта файл переименовывается в `*.test.ts`, и сохранение идёт через домен.

## Что нужно в контракте (Антон)
1. Поля `DialogueV2` (или отдельный ресурс) для незавершённых шагов: выбранное поле preview, говорящий следующей реплики, id карточки, редактируемое поле напоминаний, позиция и поиск истории.
2. Частичное сохранение ответов теста до/после.
3. Регион помощи пользователя (страна/регион) для `support()`.
4. Чтение своей оценки run (для показа выбранного «Полезно/Не полезно»).
5. Кто пишет `run_completed`: домен или клиент.
6. Серверные env-схемы вне браузерного импорта — без этого `build:web` блокируется проверкой бандла (проверку не ослабляю).
