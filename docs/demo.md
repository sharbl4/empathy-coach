# Демо на 2–3 минуты после release gates

Войти новым подтверждённым пользователем, пройти онбординг. Использовать вымышленное «Давай поговорим завтра.» без личных данных.
Указать коллегу и цель «уточнить», дать свою гипотезу или выбрать «не понимаю».
Показать альтернативы и неопределённость, затем черновик → отзыв → четыре примера.
Пройти короткое упражнение и роль с тремя ответами либо ранним finish. Показать итог и реальные счётчики.
Обновить страницу, открыть историю; показать сохранение и удаление учебных данных с объяснением сохранения аккаунта.
Резерв только явно обозначенный test/demo mock; ошибку live не скрывать. Foundation сейчас показывает лишь технический каркас, не этот сценарий.
