# Продукт: Telegram-only v1

Решение Антона 31.10.2026 заменяет браузер/Supabase/GigaChat из плана v3; учебные механики и независимые требования защиты сохранены.

Только private chat, аккаунт по Telegram ID, email подтверждается SMTP-кодом. Email/username не источник владельца. До учебной обработки — отдельное согласие и онбординг.

Обязательны:

1. Аккаунт, подтверждение email, согласие/отзыв и возобновление по Telegram ID.
2. Сообщение, отношения, контекст, цель; напоминание убрать личные данные.
3. Собственная гипотеза: эмоции, точные цитаты, «не понимаю».
4. Буквальный смысл, 2–3 альтернативы, эмоции/потребности как гипотезы, основания, неопределённость и вопрос.
5. Черновик → отзыв по фразам → улучшение; четыре цели support/clarify/reconcile/boundary, пример доступен без черновика.
6. Упражнение 30–60 секунд, попытка и отзыв.
7. Роль: три пользовательских ответа, итог; ранний finish после первого.
8. История, поиск/пагинация, сохранённые шаги после restart.
9. Прогресс без рейтинга эмпатии: ситуации, упражнения, роли, навыки, совет.
10. Имя, удаление ситуации/учебных данных/аккаунта с отдельными подтверждениями.
11. «Сказать прямо»: выразить свои чувства/потребности и уважительную просьбу, не диагностировать собеседника.
12. Понятные ошибки/ручной retry, доступные кнопки/текст, безопасное разбиение сообщений.

QQCloud зависит от домашнего ПК: при отключении доступна история, генерация сообщает ошибку. Нет обещания независимости от ноутбуков/ПК команды. Фикстуры — только явные тестовые данные, не fallback.

Нет web/MiniApp, групп, файлов/голоса/OCR, рекламы/оплаты, hosted inference и выполнения инструкций из переписки.
