## Фактические новые потоки

Telegram private updates → Node QQCloud → PostgreSQL; необходимый учебный контекст → Tailscale → домашняя Windows-модель; email/code → SMTP. Hugging Face используется только для загрузки весов, не inference; Supabase/GigaChat не runtime-поставщики. Telegram и SMTP по-прежнему могут обрабатывать персональные данные вне инфраструктуры оператора, а сеть Tailscale — метаданные в пределах своих функций; договорные роли/страны проверяются фактически.
