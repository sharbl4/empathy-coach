# Продукт v1

Нормативный полный план: ../hackathon-prompts.md, версия 3. Все 12 пунктов раздела 1 обязательны.

1. Регистрация, email confirmation, вход/выход/recovery через Supabase Auth.
2. Короткий онбординг: возможности и неопределённость трактовок.
3. Ситуация: сообщение, отношения, контекст, цель.
4. Сначала собственная гипотеза: эмоции, точные цитаты, «не понимаю».
5. Буквальный смысл, 2–3 трактовки, эмоции/потребности как гипотезы, основания, неопределённость, вопрос, сравнение гипотезы.
6. Сначала черновик, отзыв по фразам, улучшение и четыре цели: support/clarify/reconcile/boundary. Кнопка «Нужен пример» доступна без черновика.
7. Упражнение 30–60 секунд, попытка, отзыв.
8. Роль: три пользовательских ответа, естественные реплики, итог; раннее завершение после первого ответа.
9. Сохранённые шаги, поиск истории по названию, продолжение после refresh и повторного входа.
10. Прогресс: уникальные завершённые ситуации, упражнения, роли, навыки, последний совет. Без рейтинга эмпатии.
11. Имя, удаление сессии, подтверждённое удаление учебных данных с сохранением Auth-аккаунта.
12. Mobile, доступность, ошибки/retry, реальная модель, PostgreSQL, GitHub/CI/HTTPS.

Упражнение и роль доступны после успешного анализа, необязательны в каждом прохождении.
Нет оплаты, голоса, OCR, мессенджеров, социальных функций или диагностики.
Перед отправкой напомнить убрать личные данные. Не обещать удаление у провайдера/из backup без проверки.
Критерий: новый человек самостоятельно проходит путь по HTTPS; данные сохраняются, второй аккаунт их не видит.

День 1: foundation, доступы, живой анализ на staging. День 2: весь объём обучения. День 3: регрессия, release candidate, демо; после RC только блокирующие исправления.
