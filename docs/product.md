# Продукт web + Telegram v4

Решение Антона31.10.2026 заменяет Telegram-only/архив apps/web. Все функции ниже обязательны в текущем релизе; staged checkpoint не превращает остальное в roadmap. Источник — локальный team-tasks-web-telegram.md, исходный файл владельца не менялся.

## 7. Обязательный продукт — общая спецификация

| Функция | Поведение и критерий |
|---|---|
| Аккаунт | Telegram identity + подтверждённая почта; веб входит в тот же аккаунт, выход/отзыв сессий работают |
| Онбординг | Возможные трактовки, ограничения метода, где обрабатываются данные |
| Примеры | 5–10 синтетических ситуаций, реальный анализ; одна фраза с разными контекстами |
| Понять сообщение | Буквальный смысл, 2–3 версии, цитаты, осторожность выводов и вопрос |
| Своя гипотеза | До анализа: эмоции/цитаты либо «не понимаю»; затем содержательное сравнение |
| Основания | Категории опоры на текст, не проценты вероятности и не уверенное чтение мыслей |
| Сказать прямо | Переформулировка с сохранением смысла, эмоции, отказа и границ |
| До отправки | Проверка собственного черновика без требования сообщения собеседника |
| Разбор фраз | Точная цитата, возможное восприятие, замена и удачные места; веб-подсветка + Telegram-эквивалент |
| Цели ответа | Поддержать, уточнить, помириться, обозначить границу |
| Скрытие данных | Email/телефон автоматически + ручные правки; весь snapshot подтверждается до AI |
| Ветка переписки | Явные роли/порядок/редактирование, privacy preview и token budget |
| Контексты | Близкие, коллеги, преподаватель, клиент; адаптация и фильтры |
| Упражнение | Короткая задача, попытка и конкретная обратная связь |
| Ролевая игра | Три уровня, три ответа пользователя, раннее завершение, итоговый разбор |
| Практика дня | Редакционное задание, сохранение и идемпотентное завершение |
| Напоминания | Только opt-in, Telegram delivery, timezone/quiet hours/отписка/restart |
| Стрики | По локальным датам завершения, без дублей и давления |
| Навыки | Уточнение, признание переживания, просьба, граница; оценки попыток отдельно от счётчиков |
| Карточки | Проверенная короткая теория, пример и практика, версии контента и прогресс |
| До/после | Две сопоставимые формы по 3–5 заданий, рубрика 0–2, повтор через 7 дней |
| История | Общая для web/bot, поиск/фильтры/пагинация/продолжение и защита revision |
| Прогресс | Уникальные завершения и последний совет без выдуманного процента эмпатии |
| Полезность | Полезно/неполезно для своего результата, возможность изменить оценку |
| Аналитика | Воронка/популярность контекстов/полезность без содержания и внешних трекеров |
| Сложные ситуации | Контекстная ветка поддержки, проверенные региональные контакты при необходимости, без гарантии распознавания |
| Удаление | Сессия / все учебные данные / аккаунт — отдельные ясные действия с подтверждением |

Недельный тест реализуем сейчас, но реальные недельные результаты нельзя получить раньше календарного срока. Оценка модели и лайки не являются доказательством психологического эффекта. Времена/часовые пояса пользователя не выводятся из адреса сервера.
