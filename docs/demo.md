# Демо «Между строк»: web + Telegram

Хакатон «Город героев», тема «Чувствовать». Сначала gates acceptance.md, затем весь раздел7. Текущее состояние: интеграционный каркас и контракт, НЕ готовое live-демо.

С чужого телефона: private test bot → account/email/consent → своё сообщение/гипотеза → полный очищенный preview → подтверждение → настоящий анализ через QQCloud→домашнюю модель. Показать несколько трактовок/неопределённость, уточнение и сохранённые границы.
В боте нажать «Открыть веб», открыть полученную одноразовую ссылку, в браузере явно подтвердить вход и открыть ту же историю. Изменение/progress видно в обоих интерфейсах. Другой участник не видит чужие данные. Restart приложения сохраняет историю.
Отключить домашний ПК: новая генерация даёт понятную ошибку без hidden fixtures/retry, аккаунт/история/карточки читаются. Возвращение endpoint не запускает старые неоднозначные запросы автоматически.

Честно: это local inference на домашнем Windows, ПК/сеть нужны для анализа. QQCloud не запускает модель; готовность хостинга/доменов/SMTP не подтверждена. Видео прошлой генерации обозначать записью.
Gemma/Qwen4B ещё не выбраны по результатам. N=0, cold/warm TTFT/full p50/p95, local/cloud latency, VRAM и суммарная RAM неизвестны. Заполнить только после реальных измерений, не числами из ограничения Docker.
